# PyroLunar: Fire Safety Insights for a Lunar Base

**Team FrogStarz · 2026 NASA Space Apps Challenge (Antalya) · Challenge: "Flame in Freefall"**

PyroLunar is an interactive web dashboard that summarizes and compares NASA's microgravity combustion experiments from the Physical Sciences Informatics (PSI) repository. It organizes them into three fire-safety modules (**detection, extinguishment, prevention**) and shows how far each result can be trusted for a future lunar base, where oxygen will be 30% or higher and gravity will be 1/6 g.

**Target users:** researchers and engineers working on fire safety for spacecraft and lunar habitats.

## Research questions

| Module | Investigations | Research question |
|---|---|---|
| Detection | SAME, SAME-R | How do smoke and aerosols form in microgravity, and how are they measured? |
| Extinguishment | FLEX, FLEX-2 | How does diluting the atmosphere with CO₂ and helium affect flame extinction? |
| Prevention | BASS-II, SAFFIRE-II, SAFFIRE-III | Under which conditions do plastics and fabrics ignite and spread flame? |

## Key finding

Liquid fuel droplets (FLEX, FLEX-2) were tested at up to 30–34% O₂, but burning tests of **solid materials** (fabric, PMMA plastic) only reached about 22% O₂. PSI has no direct data on how fabrics and plastics in a lunar base behave at the expected oxygen level.

## Findings at a glance

- **Extinguishment:** between 17% and 21% oxygen, flames went out in 56% of FLEX tests with nitrogen only, but in 83% with added CO₂ and 81% with added helium. At 30–34% oxygen only 2 of 24 flames self-extinguished, and CO₂ and helium were never tested above 25% oxygen.
- **Prevention:** in SAFFIRE-II, silicone did not spread flame in microgravity in any of 4 samples, although 2 of them burned completely in NASA's normal-gravity screening test. No solid-material test went above 22.2% oxygen.
- **Detection:** SAME and SAME-R heated five spacecraft materials and let the smoke age from 21 s to about 32 minutes before measuring it. Measured particle sizes are in PSI's raw files, not in the experimental tables.

## Features

- Scenario selector (Earth / ISS / Lunar base) with an applicability label for every investigation
- Oxygen coverage map showing where the data stops
- Key findings for each module, computed directly from the data
- Two charts per module that answer its research question, plus filterable test tables (539 test rows)
- A three-step "How to use" guide on the overview page
- Side-by-side comparison of any two investigations
- Explicit list of missing data and limits of comparison
- Keyword search that routes users to the right module, investigation or material
- Download / copy of the cleaned table and every original PSI CSV, with DOIs

## Files

| File | Purpose |
|---|---|
| `index.html` | The dashboard (HTML + CSS + JavaScript, no libraries, charts drawn as SVG) |
| `data.js` | Cleaned dataset, generated by `prep.py` |
| `prep.py` | Python script that cleans raw PSI data into `data.js` |
| `fetch_psi.js` | Browser script that downloads the raw data from the PSI API |
| `pyrolunar.html` | `index.html` and `data.js` bundled into one file |

## How it was built

```
NASA PSI API ──(1) fetch_psi.js──▶ psi_combustion.json ──(2) prep.py──▶ data.js ──(3)──▶ index.html
```

1. **Fetch:** `fetch_psi.js` queries the PSI repository API for all 24 Combustion Science investigations and downloads their metadata and experimental tables (CSV).
2. **Clean:** `prep.py` selects the 7 investigations and maps their different column names into common fields (material, O₂ %, airflow, pressure, diluent, outcome). Missing values stay empty and appear as "no data".
3. **Display:** `index.html` reads `data.js` and renders everything in the browser.

**Run it:** open `index.html` in any browser. No server or internet connection is needed.
**Rebuild the data:** `python prep.py psi_combustion.json data.js`
